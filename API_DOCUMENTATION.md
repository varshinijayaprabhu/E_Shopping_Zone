## 1. API Architecture & Standards

All client communication (React SPA or Postman) enters the system via the **API Gateway** on port `8080`. The Gateway enforces CORS, attaches correlation IDs (`X-Correlation-Id`), validates JWT access tokens, and routes traffic downstream.

### 1.1 Ingress & Swagger UI Matrix

| Domain / Service | Gateway Base Route | Direct Service Port | Interactive Swagger UI URL |
| :--- | :--- | :---: | :--- |
| **API Gateway** | `http://localhost:8080` | `8080` | N/A (Edge Routing Reverse Proxy) |
| **Profile Service** | `http://localhost:8080/api/auth/**`, `/api/profile/**` | `8081` | [http://localhost:8081/swagger-ui/index.html](http://localhost:8081/swagger-ui/index.html) |

### 1.2 Authentication Headers & Protocols
- **Client Access Token**: `Authorization: Bearer <JWT_ACCESS_TOKEN>` (15-minute expiration, contains `sub`, `userId`, `roles`).
- **Refresh Token**: Transferred automatically in `HttpOnly; SameSite=Lax; Path=/api/auth` cookie named `refreshToken`.
- **Anti-CSRF Header**: `X-Requested-With: XMLHttpRequest` required on `/api/auth/refresh`, `/api/auth/logout`, `/api/auth/logout-all`.
- **Internal Service Secret**: `X-Internal-Secret: ESHOPPING_INTERNAL_SERVICE_SECRET_2026` required on internal Saga endpoints.
- **Correlation Tracking**: `X-Correlation-Id: <UUID>` generated by Gateway or propagated from client.

### 1.3 Standard Error Envelope
All error responses adhere to the standard JSON structure:
```json
{
  "timestamp": "2026-11-07T12:00:00Z",
  "status": 400,
  "error": "Bad Request",
  "message": "Detailed human-readable error description",
  "path": "/api/endpoint"
}
```

## 2. Profile & Authentication Microservice (`:8081`)

### 2.1 Customer Registration
- **Method / Path**: `POST /api/auth/register`
- **Access**: Public
- **Request Body**:
  ```json
  {
    "fullName": "Alice Johnson",
    "email": "customer@eshopping.com",
    "password": "Password@123",
    "phone": "+919876543210"
  }
  ```
- **Response `201 Created`**:
  ```json
  {
    "id": 1,
    "fullName": "Alice Johnson",
    "email": "customer@eshopping.com",
    "roles": ["ROLE_CUSTOMER"],
    "message": "User registered successfully"
  }
  ```

### 2.2 Merchant Registration
- **Method / Path**: `POST /api/auth/register-merchant`
- **Access**: Public (requires valid administrative invite code)
- **Request Body**:
  ```json
  {
    "fullName": "Bob Merchant",
    "email": "merchant@eshopping.com",
    "password": "Password@123",
    "phone": "+919876543211",
    "inviteCode": "ESHOPPING_MERCHANT_INVITE_2026"
  }
  ```
- **Response `201 Created`**:
  ```json
  {
    "id": 2,
    "fullName": "Bob Merchant",
    "email": "merchant@eshopping.com",
    "roles": ["ROLE_MERCHANT"],
    "message": "Merchant registered successfully"
  }
  ```

### 2.3 User Login
- **Method / Path**: `POST /api/auth/login`
- **Access**: Public
- **Request Body**:
  ```json
  {
    "email": "customer@eshopping.com",
    "password": "Password@123"
  }
  ```
- **Response `200 OK`**:
  ```json
  {
    "accessToken": "eyJhbGciOiJIUzUxMiJ9...",
    "tokenType": "Bearer",
    "expiresIn": 900,
    "user": {
      "id": 1,
      "fullName": "Alice Johnson",
      "email": "customer@eshopping.com",
      "roles": ["ROLE_CUSTOMER"]
    }
  }
  ```
- **Response Headers**:
  `Set-Cookie: refreshToken=d02f...; Path=/api/auth; Max-Age=604800; HttpOnly; SameSite=Lax`

### 2.4 Token Refresh (RTR)
- **Method / Path**: `POST /api/auth/refresh`
- **Access**: Public (Requires `refreshToken` cookie and `X-Requested-With: XMLHttpRequest`)
- **Headers**:
  - `X-Requested-With: XMLHttpRequest`
- **Response `200 OK`**:
  ```json
  {
    "accessToken": "eyJhbGciOiJIUzUxMiJ9...",
    "tokenType": "Bearer",
    "expiresIn": 900
  }
  ```
- **Response Headers**:
  `Set-Cookie: refreshToken=<NEW_ROTATED_TOKEN>; Path=/api/auth; Max-Age=604800; HttpOnly; SameSite=Lax`

### 2.5 Logout
- **Method / Path**: `POST /api/auth/logout`
- **Access**: Authenticated / Cookie bearer
- **Headers**:
  - `X-Requested-With: XMLHttpRequest`
- **Response `200 OK`**:
  ```json
  {
    "message": "Logged out successfully"
  }
  ```
- **Response Headers**:
  `Set-Cookie: refreshToken=; Path=/api/auth; Max-Age=0; HttpOnly; SameSite=Lax`

### 2.6 Logout All Devices
- **Method / Path**: `POST /api/auth/logout-all`
- **Access**: Bearer JWT (`ROLE_CUSTOMER` or `ROLE_MERCHANT`)
- **Headers**:
  - `Authorization: Bearer <TOKEN>`
  - `X-Requested-With: XMLHttpRequest`
- **Response `200 OK`**:
  ```json
  {
    "message": "All active sessions revoked successfully"
  }
  ```

### 2.7 GitHub OAuth 2.0 Code Exchange
- **Method / Path**: `POST /api/auth/oauth2/exchange`
- **Access**: Public
- **Request Body**:
  ```json
  {
    "code": "one-time-exchange-code-uuid"
  }
  ```
- **Response `200 OK`**: Returns access token and sets refresh cookie.

### 2.8 Get User Profile
- **Method / Path**: `GET /api/profile`
- **Access**: Bearer JWT
- **Response `200 OK`**:
  ```json
  {
    "id": 1,
    "fullName": "Alice Johnson",
    "email": "customer@eshopping.com",
    "phone": "+919876543210",
    "avatarUrl": null,
    "roles": ["ROLE_CUSTOMER"],
    "createdAt": "2026-11-07T08:00:00Z"
  }
  ```

### 2.9 Update User Profile
- **Method / Path**: `PUT /api/profile` and `POST /api/profile`
- **Access**: Bearer JWT
- **Description**: Updates personal details and shipping address for the authenticated user. Both `PUT` and `POST` methods are supported interchangeably.
- **Request Body**:
  ```json
  {
    "fullName": "Alice Johnson Updated",
    "phoneNumber": "+919876543299",
    "profilePictureUrl": "https://images.unsplash.com/photo-avatar.jpg",
    "addressLine1": "42 Cyber Towers",
    "city": "Hyderabad",
    "state": "Telangana",
    "postalCode": "500081",
    "country": "India"
  }
  ```
- **Response `200 OK`**: Updated profile object.

## 3. Product & Catalog Microservice (`:8082`)

### 3.1 List / Search Products
- **Method / Path**: `GET /api/products`
- **Access**: Public
- **Query Parameters**:
  - `categoryId` (optional, Long): Filter by category
  - `minPrice` (optional, BigDecimal): Filter minimum price
  - `maxPrice` (optional, BigDecimal): Filter maximum price
  - `page` (optional, Integer, default: `0`): Page number
  - `size` (optional, Integer, default: `12`): Page size
  - `sortBy` (optional, String, default: `createdAt`): Sort field (`price`, `name`, `createdAt`)
  - `direction` (optional, String, default: `desc`): `asc` or `desc`
- **Response `200 OK`**:
  ```json
  {
    "content": [
      {
        "id": 1,
        "name": "OnePlus 12 5G",
        "description": "Snapdragon 8 Gen 3, 16GB RAM, 512GB Storage",
        "price": 64999.00,
        "category": { "id": 1, "name": "Electronics" },
        "merchantId": 2,
        "imageUrl": "https://images.unsplash.com/photo-1598327105666-5b89351aff97",
        "stock": 48,
        "active": true
      }
    ],
    "page": 0,
    "size": 12,
    "totalElements": 12,
    "totalPages": 1
  }
  ```

### 3.2 Product Details
- **Method / Path**: `GET /api/products/{id}`
- **Access**: Public
- **Response `200 OK`**: Returns single product object with available stock.

### 3.3 Keyword Search
- **Method / Path**: `GET /api/products/search?keyword=laptop`
- **Access**: Public
- **Response `200 OK`**: Page of matching products.

### 3.4 Merchant Owned Products
- **Method / Path**: `GET /api/products/merchant`
- **Access**: Bearer JWT (`ROLE_MERCHANT`)
- **Response `200 OK`**: List of all products owned exclusively by the authenticated merchant.

### 3.5 Create Product
- **Method / Path**: `POST /api/products`
- **Access**: Bearer JWT (`ROLE_MERCHANT`)
- **Request Body**:
  ```json
  {
    "name": "Sony WH-1000XM5 Wireless Headphones",
    "description": "Industry Leading Noise Canceling with Auto NC Optimizer",
    "price": 29990.00,
    "categoryId": 1,
    "stock": 30,
    "imageUrl": "https://images.unsplash.com/photo-headphones.jpg"
  }
  ```
- **Response `201 Created`**: Created product entity with ID.

### 3.6 Update Product
- **Method / Path**: `PUT /api/products/{id}`
- **Access**: Bearer JWT (`ROLE_MERCHANT`) — Anti-IDOR enforced (must own product)
- **Request Body**: Fields to update (name, description, price, stock, imageUrl).
- **Response `200 OK`**: Updated product entity.

### 3.7 Delete Product
- **Method / Path**: `DELETE /api/products/{id}`
- **Access**: Bearer JWT (`ROLE_MERCHANT`) — Anti-IDOR enforced
- **Response `204 No Content`**: Product soft-deleted or deactivated.

### 3.8 List Categories
- **Method / Path**: `GET /api/categories`
- **Access**: Public
- **Response `200 OK`**: Array of all categories (`Electronics`, `Fashion & Apparel`, `Home & Kitchen`, `Books & Media`).

### 3.9 Internal Saga: Stock Reservation
- **Method / Path**: `POST /api/products/reserve`
- **Access**: Internal Microservices Only
- **Headers**:
  - `X-Internal-Secret: ESHOPPING_INTERNAL_SERVICE_SECRET_2026`
- **Request Body**:
  ```json
  {
    "orderNumber": "ORD-20261107-0001",
    "items": [
      { "productId": 1, "quantity": 2 }
    ]
  }
  ```
- **Response `200 OK`**:
  ```json
  {
    "orderNumber": "ORD-20261107-0001",
    "status": "RESERVED",
    "message": "Stock successfully reserved"
  }
  ```

### 3.10 Internal Saga: Stock Release (Compensation)
- **Method / Path**: `POST /api/products/release`
- **Access**: Internal Microservices Only
- **Headers**:
  - `X-Internal-Secret: ESHOPPING_INTERNAL_SERVICE_SECRET_2026`
- **Request Body**:
  ```json
  {
    "orderNumber": "ORD-20261107-0001"
  }
  ```
- **Response `200 OK`**:
  ```json
  {
    "orderNumber": "ORD-20261107-0001",
  ```

## 7. Admin Governance & Dispute Microservice (`:8086`)

### 7.1 Platform Overview / Big Numbers
- **Method / Path**: `GET /api/admin/metrics`
- **Access**: Bearer JWT (`ROLE_ADMIN`)
- **Response `200 OK`**:
  ```json
  {
    "success": true,
    "message": "Dashboard metrics retrieved successfully",
    "data": {
      "totalOrders": 150,
      "totalRevenue": 450000.00,
      "totalUsers": 500,
      "activeCustomers": 480,
      "registeredMerchants": 20,
      "pendingMerchants": 2,
      "pendingDisputes": 3,
      "escalatedDisputes": 1,
      "resolvedDisputes": 12
    }
  }
  ```

### 7.2 List All Merchants
- **Method / Path**: `GET /api/admin/merchants`
- **Access**: Bearer JWT (`ROLE_ADMIN`)
- **Response `200 OK`**: List of all merchants with registration timestamp, approval status, and address.

### 7.3 Approve or Suspend / Ban Merchant
- **Method / Path**: `PUT /api/admin/merchants/{id}/status`
- **Access**: Bearer JWT (`ROLE_ADMIN`)
- **Request Body**:
  ```json
  {
    "enabled": false,
    "reason": "Suspicious transaction frequency and high dispute rate"
  }
  ```
- **Response `200 OK`**: Updates status across services and writes an immutable audit log.

### 7.4 Dispute Tickets Queue
- **Method / Path**: `GET /api/admin/disputes`
- **Access**: Bearer JWT (`ROLE_ADMIN`)
- **Query Params**: `status` (e.g. `ESCALATED_TO_ADMIN`), `page`, `size`
- **Response `200 OK`**: Paginated dispute tickets.

### 7.5 Administrative Dispute Resolution & Refund Override
- **Method / Path**: `POST /api/admin/disputes/{id}/resolve`
- **Access**: Bearer JWT (`ROLE_ADMIN`)
- **Request Body**:
  ```json
  {
    "action": "REFUND",
    "adminNotes": "Admin approved full refund based on buyer photo evidence"
  }
  ```
- **Response `200 OK`**: Triggers compensating wallet refund via `order-service` Saga, releases inventory, transitions status to `REFUNDED_BY_ADMIN`, and persists audit log.

### 7.6 Admin Audit Log History
- **Method / Path**: `GET /api/admin/audit-logs`
- **Access**: Bearer JWT (`ROLE_ADMIN`)
- **Response `200 OK`**: Immutable chronological history of all administrative actions.

### 7.7 Customer Raise Dispute Ticket
- **Method / Path**: `POST /api/disputes/create`
- **Access**: Bearer JWT (`ROLE_CUSTOMER`)
- **Request Body**:
  ```json
  {
    "orderId": 101,
    "merchantId": 10,
    "issueReason": "Damaged product received",
    "customerComment": "Item box was opened and item scratched",
    "refundAmount": 1299.00
  }
  ```
- **Response `201 Created`**: Ticket initiated with status `PENDING_MERCHANT` and a 2-minute merchant SLA deadline.

### 7.8 Merchant Dispute Response
- **Method / Path**: `POST /api/disputes/{id}/merchant-response`
- **Access**: Bearer JWT (`ROLE_MERCHANT`)
- **Request Body**:
  ```json
  {
    "action": "ACCEPT",
    "responseComment": "Apologies for the damage, issuing immediate refund"
  }
  ```
- **Response `200 OK`**: If `ACCEPT`, triggers automated refund; if `REJECT`, escalates directly to `ESCALATED_TO_ADMIN`.
